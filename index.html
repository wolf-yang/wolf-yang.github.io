Agent 自进化：经验关联图与组件协同

个人研究探索

调研 CoT、ReAct、多模态推理、长链路推理可靠性与 RSI 相关工作，分析 Agent Harness 架构及轨迹驱动的组件自进化策略。

提出基于经验关联图的跨组件协同进化思路，关联成功/失败轨迹、Harness 组件与依赖关系，探索图谱引导的组件定位和联合更新；结合开源 RSI 框架开展方案设计与验证。

工业故障诊断 Agent 的双层记忆与知识检索

校企合作 · 基于 AgentPool
